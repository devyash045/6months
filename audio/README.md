# Our Song Audio File

Place your favorite couple song MP3 file here as:
`our-song.mp3`

Path: `public/audio/our-song.mp3`

If no file is present, the website automatically plays a soothing, ambient romantic arpeggio melody generated via the built-in Web Audio API synthesizer.

You can customize the track title, artist name, and special note anytime in:
`src/data/relationshipData.ts` (under `song`).
